Claude Skill

Instalar el Skill de Fontifika

El Skill es un archivo de instrucciones para Claude Code. Con él, Claude entiende casos de uso, busca 2–3 opciones y muestra un previewer visual — sin instalar el MCP.

1
Descarga el Skill con un solo comando:
mkdir -p ~/.claude/skills/fontifika && curl -o ~/.claude/skills/fontifika/SKILL.md https://fontifika.kitifica.com/SKILL.md
2
Reinicia Claude Code — el Skill se carga automáticamente al inicio de cada sesión.
3
Úsalo con lenguaje natural — o escribe /fontifika para invocarlo directamente.
necesito una fuente sans-serif para una app SaaS
1
Crea la carpeta del Skill:
mkdir -p ~/.claude/skills/fontifika
2
Descarga el archivo SKILL.md y colócalo en esa carpeta:
https://fontifika.kitifica.com/SKILL.md
3
La ruta final debe ser: ~/.claude/skills/fontifika/SKILL.md
MCP Server

Instalar el servidor MCP

Conecta Fontifika como MCP server en tu AI assistant favorito. Compatible con Claude.ai, Cursor, Windsurf, Cline y Zed.

URL del servidor MCP
https://thnmfysiwxtksehagara.supabase.co/functions/v1/api/mcp
1
Ve a Settings → Connectors
2
Haz clic en Add MCP server
3
Pega la URL y guarda — sin terminal, sin configuración extra.
https://thnmfysiwxtksehagara.supabase.co/functions/v1/api/mcp
1
Ejecuta en terminal:
claude mcp add fontifika --transport http https://thnmfysiwxtksehagara.supabase.co/functions/v1/api/mcp
2
Fontifika estará disponible en tu próxima sesión de Claude Code automáticamente.
